# What a Frozen Model Takes From Its Harness

Public record of the ARC Prize 2026 Paper Track entry: an audit of in-context learning on ARC-AGI-3 — 179 pre-registered experiments on a frozen open model in the Duck/Franzen harness.

- `paper/writeup.md` — the entry text (≤ 1,500 words)
- `paper/companion.pdf` — the long form with the full register, paired-read protocol and appendices
- `register/bets.json` — every experiment with its bar filed before its read
- `DATA.md` — what is in this tree and what is published as release assets (e.g. `transitions-3.jsonl`, 503 MB)
